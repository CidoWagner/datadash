# 🚀 DataDash Analytics

## 🧠 Dashboard Inteligente com Analista IA integrado

O **DataDash Analytics** é uma plataforma leve de Business Intelligence (BI) desenvolvida para transformar planilhas CSV e XLSX em análises visuais e insights automáticos.

O objetivo é permitir que pequenos negócios e usuários sem conhecimento avançado em dados consigam interpretar informações e tomar decisões de forma rápida e simples.

---

# ✨ Principais funcionalidades

## 📂 Importação de dados
- Upload de arquivos CSV e XLSX
- Leitura automática das estruturas das planilhas
- Identificação inteligente de dimensões e métricas

## 📊 Dashboard Inteligente
Com apenas um clique, o DataDash:

✅ Analisa a estrutura dos dados  
✅ Escolhe automaticamente os melhores indicadores  
✅ Gera gráficos automaticamente  
✅ Cria visualizações de Barras e Pizza  

---

# 🧠 Analista IA DataDash

O diferencial do projeto é o módulo de análise automática, que transforma dados em uma interpretação semelhante a um analista de negócios.

O sistema identifica:

🏆 Melhor desempenho  
📊 Participação percentual no resultado  
⚠️ Pontos de atenção  
💡 Recomendações estratégicas  

Exemplo:

> Sudeste apresentou o melhor desempenho em Receita, representando 48% do total analisado.

---

# 🎯 Problema resolvido

Muitas pequenas empresas possuem dados em planilhas, mas não possuem ferramentas ou profissionais especializados para analisar essas informações.

O DataDash reduz essa barreira oferecendo uma experiência simples:

**Planilha → Dashboard → Insights → Decisão**
